# 站定配色规范（冷静自然色板）

本项目的唯一配色来源。新增页面、组件或改版时，**只允许引用下列 Token**，不要临时写死新颜色。

设计目标：安静、清晰、自然、有秩序；能长期每天使用而不疲劳。

## 一、核心 Token

```css
:root {
  /* 背景 */
  --canvas: #f5f5f0;        /* 页面背景：温和暖灰白，降低冷硬感 */
  --surface: #ffffff;       /* 卡片背景 */
  --fill: #f2f3ee;          /* 输入框、次级填充 */

  /* 文字层级 */
  --ink: #303630;           /* 主文字 */
  --ink-2: #737a74;         /* 次要文字：说明、时间、辅助信息 */
  --ink-3: #9aa19a;         /* 更弱：占位符、空态 */

  /* 分割 */
  --hairline: #e3e6df;      /* 卡片边界与分割线 */

  /* 品牌绿：关键交互、完成与正向进展 */
  --accent: #64856b;
  --accent-strong: #5c7e63; /* 实心按钮底色（白字对比度达标） */
  --accent-deep: #4f6d55;   /* 悬停 / 按下 */
  --accent-soft: #e6eee5;   /* 浅绿背景：选中、完成、积极反馈 */

  /* 辅助蓝：时间信息与中性数据 */
  --info: #6486a3;
  --info-text: #557993;     /* 小字号时间文案（同色系加深） */

  /* 提醒 / 错误 */
  --warn: #c18b4f;
  --danger: #b85c56;

  --ease: cubic-bezier(.2, .8, .2, 1);
}
```

## 二、色彩语义（不得混用）

| 颜色 | 语义 | 允许出现的位置 |
|---|---|---|
| 绿色 | 完成、正向进展、选中 | 主按钮、实时圆点、进行中记录、自定义快捷按钮 |
| 蓝色 | 时间、信息、中性数据 | 记录时刻、时长、统计次要数据 |
| 橙色 | 提醒（不紧急） | 网络/同步提示等非致命警告 |
| 红色 | 错误与危险 | 仅删除按钮、失败提示 |
| 中性 | 其余约 80% 区域 | 背景、卡片、正文、分割线 |

硬性规则：

- 未完成、未开始一律用中性色，**不要用红色**制造负面暗示。
- 不给每个模块分配不同颜色，颜色只服务于信息识别。
- 图表用同色系深浅变化，禁止彩虹配色。
- 大面积只用低饱和、明度适中的浅色，避免高饱和与强对比。

## 三、状态色

| 状态 | 做法 |
|---|---|
| 悬停 | 实心按钮 → `--accent-deep`；浅底按钮 → 同色系加深一档 |
| 按下 | `transform: scale(.96 ~ .97)` |
| 禁用 | `opacity: .38 ~ .5`，不改色相 |
| 选中/进行中 | `--accent-soft` 底 + `--accent` 描边 |
| 焦点 | 1px `--accent` 边框 + `0 0 0 3px rgba(100,133,107,.18)` 光环 |

## 四、对比度实测

| 组合 | 比值 | 判定 |
|---|---|---|
| 主文字 / 页面背景 | 11.32:1 | 优 |
| 主按钮白字 / 绿底 | 4.55:1 | 达标 |
| 时间蓝 / 卡片白 | 4.62:1 | 达标 |
| 自定义按钮文字 / 浅绿 | 4.85:1 | 达标 |
| 次要文字 / 卡片白 | 4.73:1 | 达标 |
| 次要文字 / 页面背景 | 4.03:1 | 略低于 AA |

两处派生色是为了达标而做的同色系微调，未改变语义：

- 实心按钮用 `#5c7e63` 而非 `#64856b`（后者白字仅 4.11:1）。
- 12px 时间文案用 `#557993` 而非 `#6486a3`（后者仅 3.83:1）。

若要严格全站 AA，可把 `--ink-2` 降到 `#6b726c`。

## 五、落地位置

- 当前实现：`src/styles.css` 的 `:root`。
- 守护测试：`tests/ui.test.tsx` 中的「全站配色采用指定的冷静自然色板」，锁定 Token 不被误改。
